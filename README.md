Notebook mencakup analisis univariate, bivariate, dan multivariate. Seluruh 9 sel kode telah dieksekusi tanpa error. Subset regional memuat 1.227 catatan kota dari sembilan negara.

Sebelum dikumpulkan, isi identitas mahasiswa/kelompok pada dokumen dan periksa metadata sumber, lisensi, serta periode pengukuran. Data tidak memuat tanggal pengukuran. Dua belas label kategori pada batas AQI diaudit terpisah tanpa mengubah data asli.
